This project is an IoT-based smart fire detection and alarm system that combines:

Computer Vision using YOLO for real-time fire detection.
ESP32-based sensor monitoring.
MQTT communication for remote control and notification.
Web Dashboard for monitoring and control.
Offline operation mode when network connectivity is unavailable.

The system can detect fire from a camera stream, monitor environmental conditions using sensors, activate alarms automatically, and provide remote monitoring through MQTT and a web interface.
